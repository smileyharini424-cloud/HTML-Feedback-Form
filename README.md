# HTML Feedback Form

## Explanation

This project demonstrates how to create a simple feedback form using HTML form elements.

## Problem Statement

Create an HTML feedback form that collects the user's name, email address, rating, and comments.

## Features

* Name input field
* Email input field
* Rating selection
* Comments textarea
* Submit button
* Reset button

## How It Works

The `<form>` element is used to create the feedback form.

Text and email input fields collect basic user information.

Radio buttons allow the user to select a rating.

The `<textarea>` element is used to enter comments.

The Submit button submits the form, while the Reset button clears the entered information.

## Technologies Used

* HTML5

## Program Flow

1. Open the feedback form.
2. Enter the name.
3. Enter the email address.
4. Select a rating.
5. Enter comments.
6. Click Submit or Reset.

## Sample Input

Name: Harini
Email: [harini@example.com](mailto:harini@example.com)
Rating: Excellent
Comments: The website is easy to use.

## Sample Output

A feedback form is displayed with fields for name, email, rating, comments, Submit, and Reset buttons.
